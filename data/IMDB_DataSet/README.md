# IMDB Dataset

This folder contains the raw and processed versions of the IMDB movie review dataset used in this project.

## Files

### IMDB_Dataset.csv
Raw IMDB movie review dataset containing original text reviews and labels.

---

### imdb_textpreprocessed.csv
Cleaned and preprocessed version of the IMDB dataset.
Text has been normalized and prepared for NLP tasks.

---

### imdb_tf-idf.csv
TF-IDF vectorized version of the preprocessed IMDB reviews.
Used as input for machine learning models.

---

## Notes
- Files are ordered from raw → processed → vectorized
- This folder stores data only; no code is included here
