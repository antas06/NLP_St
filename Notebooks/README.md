# Notebooks

This folder contains Jupyter notebooks used for experimentation, preprocessing, and vectorisation of text data.

## Files

### IMDB_Dataset_preprocessing.ipynb
Notebook for cleaning and preprocessing the **IMDB Dataset**.
Includes text normalization and preparation steps before vectorisation.

---

### IMDB_vectorisation.ipynb
Notebook for applying **text vectorisation techniques** on the preprocessed IMDB Dataset.
Used to generate numerical features such as TF-IDF for modeling.

---

### text_preprocessing.ipynb
Notebook for preprocessing **movie review data fetched via the TMDB API**.
Handles cleaning and preparation of movie overview text.

---

## Notes
- Notebooks are used mainly for exploration and step-by-step experimentation
- Final, reusable logic is implemented in corresponding Python scripts
- Datasets used here are stored in the `data/` folder
